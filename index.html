▶ How to use this tool — click to expand

Every time you learn what a competitor charged — a proposal a customer shares, a renewal quote, a lost-deal debrief, a public procurement record — log it here. A few real data points per market tell us where our pricing actually sits versus the field. One quote is a rumor; five is a pattern.

Two tabs — pick the right one

  • Co-op & SSA — a co-op / shared-service deal priced across member districts. Keyed on # districts and total SPED.
  • District — a single district buying one pillar. One row per pillar (a district weighing IEP and RTI gets two rows).

Logging a quote

  1. Click + Add row or type over an example.
  2. Fill the yellow cells — competitor, their annual price, the student count covered.
  3. Set Pillar, Situation, Source from the dropdowns.
  4. The grey columns ($/student, $/SPED, multiple) fill in automatically.
Which count goes in “Covered students” (District tab)? Each pillar prices off a different group: IEP = special-ed (SPED) count · RTI = intervention students (≈ 20% of enrollment) · 504 = active 504 plans (≈ 3–4% of enrollment) · LPAC = emergent-bilingual / LEP students (≈ 12% of enrollment). Real number if you have it; the estimate is fine if not.

Reading the summaries

The Co-op tab shows entries, average competitor $/SPED, and our average cost-plus multiple. The District tab breaks it down by pillar — RTI, 504, IEP, and LPAC are separate markets with separate price ceilings, so a per-pillar read is the whole point.

The one habit that matters: this tool saves to your own browser only. To share with the team or keep a backup, click ⭳ Export CSV and drop the file in the shared location — that CSV is the team’s source of truth. ⭱ Import CSV pulls it back in (choose Add to merge or Replace to load a fresh master). Export after every logging session.

For the HubSpot admin — embedding it

One self-contained .html file, no dependencies. Either upload it to HubSpot File Manager and link the file URL from your sales tools, or add a Custom HTML module on a page and paste the file’s contents (or an <iframe> to the hosted URL). Because storage is per-browser, each rep sees their own local copy — the shared CSV stays the single source of truth. For one shared team pool, a HubSpot-native build (custom object on the deal) is the next step.
